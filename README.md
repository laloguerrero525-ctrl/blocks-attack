# Puzzle Blocks Attack

Puzzle de bloques 9×9 para bajarle al estrés, de ÑERO PRODUCHONS.

Juégalo e instálalo desde el celular: https://laloguerrero525-ctrl.github.io/blocks-attack/

- **Android (Chrome):** menú ⋮ → "Instalar app".
- **iPhone (Safari):** compartir → "Agregar a pantalla de inicio".

Es una app web instalable (PWA): `index.html` con el juego, `manifest.webmanifest`, `sw.js` para jugar sin internet e `icons/`.
